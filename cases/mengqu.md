# 孟趣：一屏，一首诗

![孟趣真实演示画面](../assets/mengqu-desktop.png)

这个小作品围绕一个简单的阅读动作展开：打开一首诗，逐字读下去。页面保留手写字体、逐字出现的动画和拼音提示；分享按钮将当前诗的链接转为二维码。

Next.js 页面通过服务端函数读取诗词，再在客户端计算逐字动画与拼音映射。分享链接带上诗词 id，让接收者打开同一首诗；“再读一首”则重新选择内容，不受当前链接 id 限制。

## 演示与修整

本次在隔离副本增加 `DEMO_MODE=true`，只使用王维与苏轼的三首公版古诗，不连接线上数据库。截图来自实际运行的生产构建。

为便于操作，两个图标按钮增加了文字标签与更清楚的颜色。核对分享流程时，还修复了一个快速换诗的边界问题：二维码退出动画结束前，组件可能已经卸载；现在会清理动画并检查容器是否仍存在。

生产构建通过。项目原有构建配置跳过 TypeScript 与 ESLint 检查，因此这里不把构建通过写成类型检查与 lint 全部通过。演示素材与私人数据库分开保存，完整仓库暂保持私有。
